
Seaching can be accessed through the dropdownmenu,
or through a key combination.

When searching, following search options should be possible:

Searching by text takes the given text and puts it into a regular
expression, then searches each card by its name in cardinfo.
Cards that are in the full cardlist, but not in the current group
will also be shown, but in a special state indicating it is not
inside the current group.

You can engulf the whole search in " quotes to
make the whole term treated as one search string.

If -I or -i or -intern or -Intern is leading, no cards outside
the current group will be shown in the search.
To instead search with this term, use "\" leading
in front of the term.

If @ immediately followed by a string, the search searches for tags with the regular expression
given. Immediately after the regular expression, you can narrow the search down by
adding ; then immediately adding a tag variable, and one of the following: (=, !=, <, >, <=, >=),
then a value. This specifies which playsetentities that have tags obeying the rules are being searched.
You can stack multiple conditions on top using ;.
Then You can add another part to the search using |. If after that a @ follows a new
tag search will be added. A search string not started by @ refers to a normal name search.

rerender():
-----------

self.playset_entity_to_cinfo = {}
self.tag_to_playset_entities = {}

full_cardlist_group: group_t = self.groups[RenderableCardlistviewer.FULL_CARDLIST_KEY]
full_cardlist: cardlist_t = Cardgroup.cardlist(group=full_cardlist_group)

for (pe_type, amount) in full_cardlist.items():

		cinfo: Renderable_CardInfo = pe_type.info()

		self.playset_entity_to_cinfo[pe_type] = cinfo

		for tag in cinfo.tags:

				if tag not in self.tag_to_playset_entities:
						self.tag_to_playset_entities[tag] = set()

				self.tag_to_playset_entities[tag].add(pe_type)
