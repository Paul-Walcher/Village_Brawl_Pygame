This class is the basic framework for a shown window instance.

It has an internal rectangle defined as frame_dim, which specifies the rectangle in which it operates in (its window size).

The internal rectangles x, y, width and height are separately stored as class varriables.

IMPORTANT: Do not change a frames frame_dim by doing frame_dim.x = ..., because internal x, y, width and height and frame_dim are adjusted using setter methods.

Each frame can also have a parent frame. If this class is discontinued using raise_exit_flag(), and the parent frames focus group is the same as this classes', the parent frame will receive the focus.

About focus groups:

A focus group is an identifier of the group the frame belongs to. Inside this group, only one frame can have the focus at one time.

You can check if you have the focus using Frame.is_focused, and focus as well as unfocus using Frame.focus and Frame.unfocus().

If you dont pass an argument for the focus group to the constructor, the frame will be assigned to a standard focus group. You should bind input received for the frame using bind_events(). Whenever focus changes for an event, all event_callbacks are cleared, and Frame.bind_events is called. There you can bind callbacks depending on whether you have the focus or not.

A frame handles pygame events by using Frame.manage_pygame_events in Frame.tick. You can register event callbacks using Frame.add_pygame_key_callback or Frame.add_pygame_event_callback.
