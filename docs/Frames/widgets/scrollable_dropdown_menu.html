153    def _calculate_depth_and_max_length(self, options):
154        #returns the depth of the deepest nested dropdown menu
155        #we use a deque in order to avoid putting to many calls on the stack
156        mdepth = deque([(options, 1)])
157        max_depth = 1
158        max_length = -1
159
160        #as long as we havent processed each option
161        while len(mdepth) > 0:
162            #getting the current option and depth
163            option, depth = mdepth.popleft()
164            #getting the amount of options in the dropdown
165            vlen = sum(
166                        1 for k in option
167                        if k != ScrollableDropdownMenu.N_OPTIONS_SHOWN_KEY
168                    )
169            max_length = max(max_length, vlen)#minus 1 for n_groups shown key
170            for v in option.values():
171                if type(v) == dict:
172                    #if any of the options values is not None, that means its a dropdown menu
173                    max_depth = max(max_depth, depth+1)#we need to check max deptg
174                    mdepth.append((v, depth+1)) #add the next option to processing
175
176        return max_depth, max_length

367

371
372        if self.state in self.move_states:
373            prev_sindex = self.selected_index
374            self.selected_index += self.moves_buffered
375            if self.selected_index < 0 and prev_sindex >= 0:
376                self.selected_index = 0

383            self.moves_buffered = 0

154    def _calculate_depth_and_max_length(self, options):
155        #returns the depth of the deepest nested dropdown menu
156        #we use a deque in order to avoid putting to many calls on the stack
157        mdepth = deque([(options, 1)])
158        max_depth = 1
159        max_length = -1
160
161        #as long as we havent processed each option
162        while len(mdepth) > 0:
163            #getting the current option and depth
164            option, depth = mdepth.popleft()
165            #getting the amount of options in the dropdown
166            vlen = sum(
167                        1 for k in option
168                        if k != ScrollableDropdownMenu.N_OPTIONS_SHOWN_KEY
169                    )
170            max_length = max(max_length, vlen)#minus 1 for n_groups shown key
171            for v in option.values():
172                if type(v) == dict:
173                    #if any of the options values is not None, that means its a dropdown menu
174                    max_depth = max(max_depth, depth+1)#we need to check max deptg
175                    mdepth.append((v, depth+1)) #add the next option to processing
176
177        return max_depth, max_length

This class is the basic framework for a shown window instance.

It has an internal rectangle defined as frame_dim, which specifies the rectangle in which it operates in (its window size).

The internal rectangles x, y, width and height are separately stored as class varriables.

IMPORTANT: Do not change a frames frame_dim by doing frame_dim.x = ..., because internal x, y, width and height and frame_dim are adjusted using setter methods.

Each frame can also have a parent frame. If this class is discontinued using raise_exit_flag(), and the parent frames focus group is the same as this classes', the parent frame will receive the focus.

About focus groups:

A focus group is an identifier of the group the frame belongs to. Inside this group, only one frame can have the focus at one time.

You can check if you have the focus using Frame.is_focused, and focus as well as unfocus using Frame.focus and Frame.unfocus().

If you dont pass an argument for the focus group to the constructor, the frame will be assigned to a standard focus group. You should bind input received for the frame using bind_events(). Whenever focus changes for an event, all event_callbacks are cleared, and Frame.bind_events is called. There you can bind callbacks depending on whether you have the focus or not.

A frame handles pygame events by using Frame.manage_pygame_events in Frame.tick. You can register event callbacks using Frame.add_pygame_key_callback or Frame.add_pygame_event_callback.
